# TechVigia ERP — Versão Acadêmica

Sistema de gestão de manutenção de CFTV (câmeras de segurança), com painel administrativo,
aplicativo móvel para técnicos, e API própria.

Esta é uma cópia de demonstração, com dados fictícios, preparada para apresentação
acadêmica.

**Documentação completa**: [`docs/README-ACADEMICO.md`](docs/README-ACADEMICO.md) — objetivo
do sistema, arquitetura, como executar, usuários de demonstração, e as diferenças em
relação à versão usada pela empresa de origem.
